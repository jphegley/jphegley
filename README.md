# Hey, I'm Jordan 👋

I'm a software engineer who builds full-stack products and automates all the pieces I can. I ship **[Magpie](https://magpie.services)**, a collections management platform, and for a day job, I build cloud integrations and engines for enterprise site and asset management platforms.

## 🐦‍⬛ Magpie — Collections Management

**[magpie.services](https://magpie.services)** · **[Docs](https://docs.magpie.services)**

A full-stack, production app for organizing, cataloging, and sharing collections of anything: vinyl, trading cards, books, cameras, board games. Web and mobile, with sync across both.

| Layer | Stack | Highlights |
|-------|-------|------------|
| Web | React 19, Vite, Tailwind CSS 4 | Collections, folders, smart collections, analytics dashboard, import/export |
| Mobile | React Native, Expo | iOS and Android, offline support, barcode scanning, biometric auth, push notifications |
| API | Go, Gin, PostgreSQL (Supabase) | Auth, sharing permissions, Stripe billing, Cloudflare R2 file storage |
| Edge | Cloudflare Workers | API proxy and static assets |

> The Magpie repos are private. The product and its docs are public at the links above.

## 🏗️ Day Job

I build tooling for teams running site and asset work on configurable enterprise platforms:

- **Cloud integrations** as Azure Functions with infrastructure as code and CI-driven deploys
- **Engines and dashboards** in Oracle PL/SQL that run inside the platform itself
- **A platform-agnostic toolkit** of shared practices and adapters that teams layer a tenant overlay onto
